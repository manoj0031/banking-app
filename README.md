

\# Banking Application



\## Description

A simple Python-based Banking Application to manage account details, balance, and account types.



\## Features

\- View Account Details

\- Check Account Balance

\- View Account Type



\## Technologies

\- Python

\- Git

\- GitHub



\## Git Workflow

\- Developer 1 adds Account Balance.

\- Developer 2 adds Account Type.

\- Merge both branches.

\- Resolve merge conflicts manually.



\## Conclusion

This project demonstrates Git branching, merging, and manual merge conflict resolution.
